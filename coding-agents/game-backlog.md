# Backlog

Feature ideas for the game. Agent N builds item N on its own branch. Change any item,
then commit and push before you start the agents.

Adapt your item to this game's mechanic, controls, and visual style. Keep its core
concept: a puzzle, a racer, and a rhythm game should get different implementations
of the same idea.

1. A milestone challenge after a streak of successful moves.
2. Night mode with a spotlight that follows the action.
3. A new avoidable hazard with a clear warning before it acts.
4. Two-player co-op on one keyboard.
5. A twist round that reverses one core rule, then returns to normal.
6. A combo multiplier for successful moves in a row.
7. A shop between rounds that sells one upgrade.
8. A precision mode with a smaller safe timing window or target area.
9. Decoys that reward careful decisions and are visibly distinguishable.
10. A speedrun timer and a best time.
11. An environmental effect that periodically changes how you plan a move.
12. A rare bonus objective worth ten points that fits the game's world.
13. A daily challenge seeded from today's date.
14. Brief particles and satisfying visual feedback on successful moves.
15. A rhythm mode that rewards moves on a visible beat.
16. Mirror mode: the controls are swapped.
17. A tiny challenge editor for the game's goals or starting layout.
18. Clear remaining chances with an animation when one is gained or lost.
19. An attract mode that plays itself on the title screen.
20. A photo finish: replay the last five seconds in slow motion.
